## Variables and data types

Variables are named storage locations in memory. Each variable has a data type that determines what kind of data it can hold.

Common data types:

- **Integer** — whole numbers (e.g., `42`, `-7`)
- **Float / Double** — decimal numbers (e.g., `3.14`, `-0.5`)
- **Boolean** — true or false
- **Char** — a single character (e.g., `'a'`, `'9'`)
- **String** — a sequence of characters (e.g., `"hello"`)

## Operators

### Arithmetic Operators

| Operator | Description         | Example  |
| -------- | ------------------- | -------- |
| `+`      | Addition            | `a + b`  |
| `-`      | Subtraction         | `a - b`  |
| `*`      | Multiplication      | `a * b`  |
| `/`      | Division            | `a / b`  |
| `%`      | Modulus (remainder) | `a % b`  |
| `**`     | Exponentiation      | `a ** b` |

### Comparison Operators

| Operator | Description              |
| -------- | ------------------------ |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |

### Logical Operators

| Operator      | Description                                  | Truth Table                   |
| ------------- | -------------------------------------------- | ----------------------------- |
| `&&` / `AND`  | Returns true if both operands are true       | `T && T = T`, otherwise `F`   |
| `\|\|` / `OR` | Returns true if at least one operand is true | `F \|\| F = F`, otherwise `T` |
| `!` / `NOT`   | Negates the operand                          | `!T = F`, `!F = T`            |

## Control Flow

### If-Else Statements

Conditional branching based on boolean expressions:

```
IF condition THEN
    // code block
ELSE IF other_condition THEN
    // code block
ELSE
    // code block
END IF
```

### Loops

**For loop** — iterate a known number of times:

```
FOR i = 0 TO n-1
    // code block
NEXT i
```

**While loop** — iterate while a condition is true:

```
WHILE condition
    // code block
END WHILE
```

## Sub-programs (Functions / Methods)

A named block of code that performs a specific task:

```
FUNCTION calculateSum(a, b)
    RETURN a + b
END FUNCTION
```

**Benefits:**

- **Modularity** — breaks complex problems into smaller parts
- **Reusability** — write once, use many times
- **Maintainability** — easier to debug and update
